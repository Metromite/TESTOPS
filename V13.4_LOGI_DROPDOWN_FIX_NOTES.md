# DispatchOPS V13.4 — LOGI + Dropdown Fix

- LOGI Edge Function deployed to Primary as version 13.
- Supabase Data Assistant is now a first-class live-data provider instead of being filtered out of the provider chain.
- `best route area` is handled from live `route_assignments` data using average planner score, with top area/ranking returned.
- Groq, OpenAI, OpenRouter, Gemini and Claude now use their correct API adapters. Ollama remains local-only and therefore cannot be reached by the hosted Edge Function.
- External provider failures fall back to live-data answers without exposing provider errors.
- Dashboard Export dropdown keeps the no-flicker compositing fix but now has a denser frosted-looking surface in light/dark themes.
- Predictive Autocomplete now shows initial suggestions on focus and has a fallback query for Driver/Helper data.
- Bulk Organizer files were not intentionally changed by this fix.

Verification:
- TypeScript transpile/syntax checks passed for modified TS/TSX files.
- Full npm/Vite build was not run because this working copy does not contain installed dependencies/lockfile.
