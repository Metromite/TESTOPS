# V35.45 — Bulk Organizer Restore

Targeted fix for the Bulk Organizer historical-plan/invoice regression.

- Primary planner data is now canonical when a Primary row exists.
- Tertiary is a fallback only when Primary has no row.
- Realtime Primary plan updates re-read through the canonical loader instead of blindly spreading a realtime payload over the current plan.
- Date-loading requests are generation-checked so an older date request cannot overwrite a newer selected date.
- No database rows are deleted or migrated by this release.
