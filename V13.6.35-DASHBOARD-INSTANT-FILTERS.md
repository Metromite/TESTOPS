# V13.6.35 — Dashboard Zero-Box + Excel-Like Instant Filters

- Hard-fix Dashboard Home Valid Invoices so `boxes <= 0` can never enter the KPI/chart base.
- Fleet driver identity remains authoritative for dashboard driver rows.
- Fleet vehicle type is canonicalized to `Pickup` or `Van`.
- Dashboard month data is warmed once and cached in IndexedDB.
- Home filtering uses the warmed local dataset instead of a Supabase round-trip when available.
- Dynamic Driver slicer is computed locally from the warmed dataset.
- Landmark route data is warmed/cached once per month for Home route KPI calculations.
- Home ignores Lead Time Band / Classification changes because those filters only belong to the Lead Time tab.
- Existing server RPC remains as a fallback if the local dataset has not finished warming.
- No Bulk Organizer changes.
