# DispatchOPS V35.41 – Targeted Driver / Bulk / Permissions Fixes

## Dashboard driver slicer
- Restored the Fleet Database display format to `CODE · NAME`.
- Driver filter matching now accepts Fleet driver code or Fleet driver name and normalizes case/spacing.
- The initial latest-data lookup uses the Primary operational database directly, avoiding a federated-read failure from leaving the dashboard on an empty current month.
- No dashboard KPI calculation logic was intentionally changed.

## Bulk Organizer
- Federated plan loading now merges invoice arrays from Primary + Tertiary instead of taking only the first non-empty array.
- The daily plan becomes writable immediately after the saved plan is hydrated, so a slow/failing secondary SAP enrichment phase cannot block manual invoice autosave.
- Duplicate invoices are suppressed by invoice id or invoice number, with Primary taking precedence when the same invoice exists in both projects.
- Month-plan invoice merging uses the same rule.
- Existing invoices remain date-specific; invoices are not copied from one planning date to another.
