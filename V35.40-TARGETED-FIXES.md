V35.40 targeted fixes

1. Dashboard driver slicer
- Display uses the Fleet Database canonical driver name followed by Fleet code.
- Driver options remain backed by Fleet Database records and are only included when matching dashboard/SAP data exists.
- Old slicer cache key remains invalidated via v4.

2. Bulk Organizer data federation
- Primary and Tertiary bulk plans are merged instead of letting an empty row in one DB hide populated data in the other.
- When a selected date has an empty structural plan, the nearest populated plan in the same month supplies vehicles/buildings/schedules only. Date-specific invoices/assignments are never copied.
- Monthly plan reads now merge both databases.
- Existing ownership-on-save behavior remains data-aware.

3. Permissions
- Fleet and Vacations: all authenticated users can add/edit/export; only admins can Excel-import.
- Experience: users can view/download; admins can import/reset.
- Imports: only admins can upload/process or delete imported batches.
- Location Knowledge: users can add/edit/download; admins retain Excel learning/management import, delete, and reset.
- Customer Intelligence: users can search/download; admins additionally can import and delete.

4. No Price Change behavior was changed.
