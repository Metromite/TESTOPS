V13.3 FIX NOTES

1. Dashboard glass stability
- Rebuilt the Dispatch Operations dashboard header/export glass layers onto stable compositing surfaces.
- Removed live backdrop-filter sampling from the header and Excel export menu to eliminate mouse-move shimmer/flicker.
- Kept frosted translucent material, fixed positioning, stacking, and menu behavior.

2. Dashboard automatic latest-month filter
- Dashboard now checks Primary + Secondary + Tertiary for the latest imported SAP dispatch_date.
- On initial entry it defaults From/To to the full latest data month.
- When a newer SAP month arrives through import/realtime, the dashboard automatically moves its date filter to that newer month.
- Existing manual date selection is not overwritten unless a newer month than the current selected month is detected.

3. LOGI
- Deployed logi-agent V12.
- Simple greetings such as "hi" now receive a normal greeting instead of a provider-unavailable fallback message.
- Provider failures no longer expose the old provider-unavailable text.
- Highest-area-by-order remains a live-data deterministic query across Primary + Secondary SAP facts.

4. Bulk Organizer
- No Bulk Organizer logic was changed in this release.
