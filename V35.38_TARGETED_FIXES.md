# DispatchOPS V35.38 — Targeted Fixes

- Bulk Organizer retention: on the 8th of each month, previous-month and older Bulk Organizer plans/month defaults are deleted. Current/future month data is untouched.
- Fleet permissions: authenticated users can add/edit/import/export; destructive Delete/Undo controls are removed from the application UI.
- Customer Intelligence: search/read only; no Reject/Delete action.
- Recent Updates: Admin AI & Account Settings shows the latest five audit updates with actor and changed fields.
- Startup performance: removed the Primary→Secondary configuration sync from every app startup.
- Connection banner: removed from normal pages; database health is shown in Admin AI & Account Settings.
- Dashboard driver slicer: restricted to drivers that actually exist in Fleet Database (code/name).
- Background performance: cached signed wallpaper URLs are reused immediately and wallpaper uploads are lightly resized/compressed to WebP when beneficial.
- Login protection: five failed attempts locally lock ordinary accounts until Admin Settings unlocks them. A server-side migration is also included in `supabase/migrations/0064_login_lockout_and_admin_unlock.sql` for persistent enforcement when migrations are applied.
